MAE por dia do horizonte

LightGBM e baseline usam só lags de 7 dias ou mais, por isso o erro deles quase não muda de D+1 a D+7. O AutoETS usa o último dado e acerta melhor em D+1, mas piora rápido. Isso indica ganho possível com modelos diretos por horizonte.

8Reprodutibilidade

Como rodar

Pipeline completo + esta página

uv sync --python 3.12
uv run python -m src.run_pipeline

Abrir a página com o MLflow ligado

uv run python -m src.serve

Sobe a interface do MLflow (porta 5000) e esta página (porta 8000). Os links de cada run passam a abrir direto no MLflow.

O que eu faria com mais tempo

  1. Temperatura (INMET/Open-Meteo) ponderada por população das capitais do SE: ondas de calor explicam os maiores erros.
  2. Modelos diretos por horizonte: D+1 poderia usar lags de 1 a 6 dias, e quantis (P10/P50/P90) apoiariam a reserva operativa.
  3. Reconstituir a série pré-MMGD: hoje o degrau de mai/2023 é tratado com variáveis de regime. Com a série de MMGD do ONS daria para corrigir o histórico.
